Memory tape

  
Brainfuck has no variables, only a row of byte cells and a pointer. The named cells hold the game state; the rest are scratch cells used for comparisons and arithmetic. The outlined cell is where the pointer sits when the frame is printed.

  






  

    
The program

    
  

  
The source was generated by a small compiler written in Python, which turns if, while and comparisons into raw Brainfuck. Paste it into any Brainfuck interpreter: , reads 1 to flap or 0 to fall, and each frame ends with a form feed.
